# RTS Voyage - Visual Prototype

`rts-slg`의 Godot 4.7 + C#/.NET 구조와 저폴리 3D 방향을 참고한 독립적인 항해 게임 화면 프로토타입입니다.

## 현재 포함

- 저폴리 바다
- 대륙/섬
- 해변
- 산맥
- 숲
- 항구 마을/잔교
- 간단한 범선
- 쿼터뷰 카메라
- WASD 카메라 이동
- 마우스 휠 줌
- 우클릭 드래그 회전

외부 에셋 없이 Godot 기본 Mesh를 코드에서 조합하므로 프로젝트만으로 바로 화면을 확인할 수 있습니다.

## 실행

Godot 4.7.x .NET(Mono) 버전과 .NET 9 SDK가 필요합니다.

1. `run.bat`의 `GODOT_FALLBACK` 경로가 로컬 Godot 경로와 맞는지 확인합니다.
2. `run.bat` 실행

기존 `rts-slg`와 같은 위치에 Godot 4.7.2 Mono가 있다면 기본값 그대로 동작하도록 작성했습니다.

## 빌드 확인

`build.bat`
